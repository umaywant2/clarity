Semantic API Spec — TriadicFrameworks

Base URL

https://triadicframeworks.com/api/semantic

Endpoints

1. GET /concept

Resolve a concept into ontology, lexicon, and module references.

GET /api/semantic/concept?term={string}
  • term: concept name (e.g., spectral clarity)

Response (JSON):

{
  "term": "spectral clarity",
  "ontology_node": "ONT:CLARITY.SPECTRAL",
  "lexicon_entry": "/docs/si_lexicon.html#spectral-clarity",
  "modules": ["clarity"],
  "docs": [
    "/clarity/spectral_clarity.html",
    "/docs/si_knowledge_base.html#spectral-clarity"
  ]
}

2. GET /module

Retrieve semantic metadata for a canonical module.

GET /api/semantic/module?id={string}
  • id: one of CLARITY, COHERENCE, DRIFT, REGIME, MODULE, SESSION

Response (JSON):

{
  "id": "CLARITY",
  "name": "Clarity",
  "category": "spectral-math",
  "operators": [
    "CLARITY-Compute",
    "CLARITY-Validate",
    "CLARITY-Integrate",
    "CLARITY-Explain"
  ],
  "resonance_fields": [
    "SpectralClarity",
    "ValidatorPulse",
    "IntegrationField"
  ],
  "docs": [
    "/clarity/index.html",
    "/clarity/spectral_clarity.html",
    "/clarity/validator_pulses.html"
  ]
}

3. GET /ontology

Retrieve ontology node details.

GET /api/semantic/ontology?node={string}
  • node: ontology ID (e.g., ONT:DRIFT.ENVELOPE)

Response (JSON):

{
  "node": "ONT:DRIFT.ENVELOPE",
  "label": "Drift Envelope",
  "description": "Canonical RTT construct describing bounded drift behavior.",
  "related_terms": ["drift velocity", "oscillation family"],
  "modules": ["drift", "regime"],
  "docs": [
    "/drift/drift_envelope.html",
    "/docs/si_ontology.html#drift-envelope"
  ]
}

4. GET /lexicon

Retrieve lexicon entry.

GET /api/semantic/lexicon?term={string}

Response (JSON):

{
  "term": "validator pulse",
  "definition": "Discrete spectral event used to validate clarity across RTT operations.",
  "category": "spectral-math",
  "modules": ["clarity"],
  "docs": [
    "/clarity/validator_pulses.html",
    "/docs/si_lexicon.html#validator-pulse"
  ]
}

5. GET /map

Retrieve cross‑module integration relationships.

GET /api/semantic/map

Response (JSON):

{
  "integration_map": "/integration_map/index.html",
  "edges": [
    {
      "from": "clarity",
      "to": "coherence",
      "relation": "SpectralClarity → AlignmentField"
    },
    {
      "from": "coherence",
      "to": "drift",
      "relation": "AlignmentField → DriftEnvelope"
    }
  ]
}
