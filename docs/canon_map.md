# **TriadicFrameworks — Canon Map (R5)**  
### File: `/docs/canon_map.md`

## **1. Canon Overview**

The TriadicFrameworks Canon is organized into five major structural domains:

1. **Triadic Structure (S‑R‑A)**  
2. **Substrate Primitives**  
3. **Evaluator Lineage**  
4. **Analyzer Layers**  
5. **Module Architecture**

This map shows how each domain connects to the others.

---

## **2. Triadic Structure Map**

```
Structure (S)   → form, constraint, axis
Resonance (R)   → relation, harmonic, field
Activation (A)  → impulse, motion, surge
```

Every evaluator, module, and semantic entity maps to one or more triadic layers.

---

## **3. Substrate Primitive Map**
