# 🜁 **SESSION TEMPLATES — MODULE MODEL**  
### *Identity • Roles • Lineage • Analyzer Layers*

## **Session 1 — Module Identity (S‑Pulse)**  
**Goal:** Teach the structural identity of a module.

**Structure (S):**  
Define module identity, roles, schema.

**Resonance (R):**  
Map lineage: parent → siblings → children.

**Activation (A):**  
Show how module behavior emerges from analyzer layers.

**Substrate:**  
ΔS/ΔR/ΔA → metadata shifts  
Op → lineage oscillation  
Rg → module regime

**RTT:**  
Drift → metadata instability  
Coherence → lineage alignment  
Regime → module mode  
Clarity → identity pulse

**Exercise:**  
Write a module.json for a new module.

**Clarity Target:**  
C1 — structural clarity.
