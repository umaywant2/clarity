# Temporal Mesh Engine

**RTT Inside / Mesh Node • Temporal and Drift-Aware Intelligence Architecture**

The **Temporal Mesh Engine** is the RTT/Store Intelligence entry point associated with the existing **RTT Inside / Mesh Node** source lineage.

It packages that material as a temporal and mesh-oriented Intelligence architecture for discovery, navigation, and drift-aware structural reasoning.

The Temporal Mesh Engine does not replace or redefine Mesh Node.

The Store term **Engine** provides a stable architectural identity while leaving temporal behavior, mesh relationships, node mechanics, and implementation details grounded in their originating source material.

## Temporal Drift vs. Conceptual Drift

The Store should also avoid collapsing every use of the word `drift` into the same mechanism.

Two broad concerns may appear during exploration:

### Structural or Temporal Drift

Drift explicitly defined by the originating architecture or source material.

### Interpretive Drift

Drift introduced when a reader, Store page, or AI assistant gradually moves away from the declared source, context, or meaning.

The Store manifest establishes drift as an analysis lens.

It does not automatically declare these forms equivalent.

Where the Mesh Node source provides a more precise definition, that definition takes precedence.
