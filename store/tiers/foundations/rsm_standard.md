# RSM Standard

**Resonance Substrate Model • Foundations Reference**

The **RSM Standard** is the RTT/Store entry point for the **Resonance Substrate Model (RSM)**.

It packages the existing RSM material as a Foundations-level reference for discovery, orientation, and reuse.

The RSM Standard does not create a separate Store version of the Resonance Substrate Model. Definitions, structures, operators, and interpretations remain grounded in the originating RSM source material.

---

## Store Role

**Tier:** Foundations  
**Role:** Reference  
**Analyzer layer:** Regime  
**Status:** Reference  
**Source family:** Resonance Substrate Model

The Store treats RSM as an established source lineage rather than a product definition invented at the storefront layer.

---

## Purpose

The RSM Standard provides a stable Store-facing route into Resonance Substrate Model material.

Its purpose is to:

- make RSM easier to locate from the RTT/Store
- preserve a clear connection to its originating documentation
- provide a common reference point for later Store tiers
- support human and AI navigation of the RTT ecosystem
- distinguish source material from Store packaging

Detailed RSM definitions should be taken from the source documentation rather than reconstructed here.

## Placement in Foundations

Foundations provides the orientation and reference layer of the RTT/Store.

Within that tier, the RSM Standard complements:

- **RTT Primer** — RTT orientation and entry
- **RTTCodes Pack** — code-oriented reference artifacts
- **Canon Starter Pack** — guided access to selected canonical material
- **RSM Standard** — Store-facing access to the Resonance Substrate Model

Together these artifacts establish reference points before the Store progresses into operational Systems and higher-order Intelligence architectures.

## Regime Lens

The Store manifest assigns the RSM Standard to the **regime** analyzer layer.

For Store purposes, that classification acts as a navigation and analysis label. It should not be used here to impose new theoretical claims on RSM.

Any substantive explanation of RSM regime structure should remain grounded in the RSM source documentation.

## Use with AI

When using the RSM Standard as an AI entry point, preserve both **context** and **provenance**.

```text
rtt=1 | coherence=declared | drift=bounded | paradox=structural
```

An AI assistant should treat this Store page as a routing and orientation artifact.

For deeper RSM interpretation:

1. follow the RSM source lineage
2. distinguish source definitions from Store descriptions
3. preserve established terminology
4. avoid filling undefined concepts through inference
5. return to the RTT Spine when broader framework context is required
