# Horizon Agent Pack

**Long-Horizon Continuity Agents • Systems Architecture**

The **Horizon Agent Pack** is the RTT/Store Systems entry point associated with the existing **Long Horizon Continuity Agents** lineage.

It packages that material as a discoverable Systems-level artifact for architectural navigation, continuity-oriented exploration, and connection to related RTT structures.

The Horizon Agent Pack does not create a separate definition of the underlying agents.

The Store term **Pack** describes a presentation and packaging layer around the source material. It does not imply that the Pack is itself a finished agent platform, deployable software product, or independent source of RTT canon.

## Long-Horizon Boundary

The phrase **long horizon** is intentionally preserved from the source lineage.

At the Store layer, it should not be converted into an arbitrary duration, persistence guarantee, autonomy claim, or operational capability.

The Horizon Agent Pack therefore preserves three boundaries:

### Established Source

Agent concepts, structures, behaviors, terminology, and mechanisms explicitly established in the Long Horizon Continuity Agents documentation.

### Store Representation

The organization and presentation of that lineage as the **Horizon Agent Pack** within the Systems tier.

### Future Extension

Any agent architecture or capability that extends beyond the established source.

Future extensions should be labeled explicitly rather than silently incorporated into the Pack.
